### \3. JavaScript 핵심 기능

#### ① 영화 추가 및 말줄임표 툴팁

```javascript
function addMovie(title) {
  const movieTitle = title || document.getElementById('movieInput').value;
  if (!movieTitle) return;

  const card = document.createElement('div');
  card.className = 'movie-card';
  card.draggable = true; // 드래그 가능하게 설정
  card.title = movieTitle; // 마우스 올리면 전체 제목 표시 (툴팁)

  card.innerHTML = `<span class="movie-title">${movieTitle}</span>`;
  
  // 클릭 시 이동 기능 (예: 클릭하면 다음 등급으로 순환)
  card.onclick = () => moveNextTier(card);
  
  // 드래그 이벤트 리스너 추가 (생략)
  
  document.getElementById('unclassified').appendChild(card);
  saveToLocal(); // 로컬 스토리지 저장
}
```

#### ② 드래그 앤 드롭 (Drag &amp; Drop)

브라우저 기본 API를 사용하여 카드를 원하는 구역에 놓을 수 있게 합니다.

#### ③ 로컬 스토리지 (LocalStorage)

현재 등급 상태를 JSON 형태로 저장하고, 페이지를 새로고침할 때 다시 불러옵니다.

```javascript
function saveToLocal() {
  const data = {};
  document.querySelectorAll('.drop-zone').forEach(zone => {
    const tier = zone.parentElement.dataset.tier || 'unclassified';
    const movies = Array.from(zone.children).map(card => card.title);
    data[tier] = movies;
  });
  localStorage.setItem('myMovieTier', JSON.stringify(data));
}
```

#### ④ 이미지 저장 (html2canvas 라이브러리 추천)

웹 화면을 그대로 캡처하기 위해 `html2canvas`라는 외부 라이브러리를 사용하면 매우 간단합니다.

```javascript
function saveAsImage() {
  html2canvas(document.querySelector("#tier-container")).then(canvas => {
    const link = document.createElement('a');
    link.download = 'my-tier-list.png';
    link.href = canvas.toDataURL();
    link.click();
  });
}
```

# 🎬 영화 티어리스트(Movie Tier List) 기획서

## \1. 누가 쓰나 (Target Audience)

- **영화 애호가:** 자신이 본 영화를 등급별로 정리하고 기록하고 싶은 사람.
- **커뮤니티 사용자:** 자신의 영화 취향을 시각적인 자료로 만들어 친구나 온라인 커뮤니티에 공유하고 싶은 사람.

## \2. 무엇을 하려고 (Purpose)

- **시각적 분류:** 영화들을 S, A, B, C 등급으로 나누어 한눈에 파악할 수 있게 함.
- **데이터 보존:** 브라우저를 껐다 켜도 내가 설정한 티어 리스트가 그대로 유지되게 함.
- **공유 편의성:** 완성된 티어리스트를 별도의 캡처 도구 없이 이미지 파일로 즉시 저장함.

## \3. 화면과 동작 (UI &amp; Interactions)

### 🖼 화면 구성

- **입력부:** 영화 제목 입력창과 '추가' 버튼.
- **티어 영역:** S, A, B, C 등급별 행(Row). 각 행 왼쪽에는 등급 라벨이 있고, 오른쪽에는 영화 카드가 들어갈 빈 공간이 있음.
- **미분류 영역:** 추가된 영화나 아직 등급을 매기지 않은 영화들이 모여 있는 하단 영역.
- **하단 버튼:** '이미지로 저장하기' 버튼.

### ⚙️ 주요 동작

- **영화 추가:** 제목 입력 후 엔터 키를 누르거나 추가 버튼 클릭 시 '미분류' 영역에 영화 카드 생성.
- **영화 이동 (2-Way):**
  
  1. **드래그 앤 드롭:** 카드를 마우스로 끌어서 원하는 등급 칸에 배치.
  2. **클릭 이동:** 카드를 클릭하면 순차적으로 다음 등급 칸으로 이동 (미분류 → S → A → B → C → 미분류).
- **가변 UI:**
  
  - 영화 카드가 많아지면 등급 칸의 높이가 자동으로 늘어남.
  - 영화 카드가 삭제되거나 이동하여 줄어들면 최소 높이로 복구됨.
  - 화면 너비에 따라 영화 카드가 자동으로 줄바꿈됨 (반응형).
- **카드 디테일:**
  
  - 제목이 길 경우 카드 내에서 말줄임표(...) 처리.
  - 카드에 마우스를 올리면(Hover) 전체 제목이 툴팁으로 표시됨.

## \4. 필요한 자료 (Resources)

- **초기 영화 데이터:** 
  
  - 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리.
- **기술 스택:**
  
  - **HTML5 / CSS3:** 레이아웃 및 가변 디자인 구현.
  - **Vanilla JavaScript:** 드래그 앤 드롭, 클릭 로직, LocalStorage 제어.
  - **html2canvas (Library):** 웹 화면을 이미지(PNG)로 변환하기 위한 라이브러리.

## \5. 완성 기준 (Definition of Done)

1. **동작성:** 영화 추가, 드래그 앤 드롭, 클릭 이동 기능이 오류 없이 작동한다.
2. **지속성:** 페이지를 새로고침해도 배치한 영화들의 위치가 그대로 유지된다.
3. **반응성:** 창 크기를 조절해도 요소가 겹치거나 잘리지 않고 자연스럽게 배치된다.
4. **출력:** '이미지 저장' 버튼 클릭 시 현재 구성된 티어리스트가 이미지 파일로 다운로드된다.

- **데이터 내보내기:** 현재의 티어 상태를 JSON 파일로 다운로드하여 데이터 형태로 보관.

## \3. 화면과 동작 (UI &amp; Interactions)

### 🖼 화면 구성

- **입력부:** 영화 제목 입력창과 '추가' 버튼.
- **티어 영역:** S, A, B, C 등급별 행(Row). 각 행은 고유 색상의 라벨을 가짐.
- **미분류 영역:** 추가된 영화 카드가 최초로 생성되는 대기 장소.
- **하단 버튼:** 'JSON으로 저장하기' 버튼.

### ⚙️ 주요 동작

- **영화 추가:** 제목 입력 후 엔터 키 또는 버튼 클릭 시 '미분류' 영역에 카드 생성.
- **영화 이동 (2-Way):**
  
  1. **드래그 앤 드롭:** 마우스로 카드를 끌어서 원하는 등급 칸/미분류 칸으로 자유롭게 이동.
  2. **클릭 이동:** 카드 클릭 시 다음 등급으로 자동 순환 (미분류 → S → A → B → C → 미분류).
- **가변 UI &amp; 반응형:**
  
  - 영화 카드가 많아지면 등급 칸의 높이가 유연하게 늘어남 (Flexbox 활용).
  - 화면 너비가 좁아지면 카드가 자동으로 다음 줄로 넘어감 (Wrap).
- **카드 디테일:**
  
  - **말줄임표:** 카드 너비를 벗어나는 긴 제목은 `...`으로 생략.
  - **툴팁:** 카드에 마우스를 올리면 브라우저 기본 툴팁(`title` 속성)으로 전체 제목 표시.

<script>
    let selectedCard = null; // 현재 선택된 카드를 추적

    window.onload = () => {

    function createMovieCard(title) {
        const card = document.createElement('div');
        card.className = 'movie-card';
        card.draggable = true;
        card.title = title;
        card.id = 'movie-' + Date.now() + Math.random();
        
        card.ondragstart = (e) => {
            deselectAll(); // 드래그 시작 시 선택 상태 해제
            e.dataTransfer.setData("text", e.target.id);
        };

        // 카드 클릭 시 선택 로직
        card.onclick = (e) => {
            e.stopPropagation(); // 부모(행)의 클릭 이벤트가 발생하지 않도록 방지
            toggleSelect(card);
        };

        card.innerHTML = `<span class="movie-title">${title}</span>`;
        return card;
    }

    // 카드 선택/해제 토글
    function toggleSelect(card) {
        if (selectedCard === card) {
            deselectAll();
        } else {
            deselectAll();
            selectedCard = card;
            card.classList.add('selected');
        }
    }

    function deselectAll() {
        if (selectedCard) {
            selectedCard.classList.remove('selected');
            selectedCard = null;
        }
    }

    function moveSelectedHere(zoneElement) {
        if (!selectedCard) return;

        let targetZone;
        if (zoneElement.classList.contains('tier-row')) {
            targetZone = zoneElement.querySelector('.drop-zone');
        } else {
            targetZone = zoneElement; // 미분류 영역인 경우

            input.value = '';
            saveData();
        }
    }

    // 드래그 앤 드롭 (기존 기능 유지)
    function allowDrop(e) { e.preventDefault(); }
    function drop(e) {
        e.preventDefault();
        const data = e.dataTransfer.getData("text");
        const card = document.getElementById(data);
        let target = e.target;
        while (target && !target.classList.contains('drop-zone') && !target.classList.contains('unclassified-zone')) {
            target = target.parentElement;

            saveData();

    function saveData() {
        const data = {
            S: getTitlesFromZone('.tier-row:nth-child(1) .drop-zone'),
            A: getTitlesFromZone('.tier-row:nth-child(2) .drop-zone'),
            B: getTitlesFromZone('.tier-row:nth-child(3) .drop-zone'),
            C: getTitlesFromZone('.tier-row:nth-child(4) .drop-zone'),
            unclassified: getTitlesFromZone('#unclassified')
        };

    }

    function getTitlesFromZone(selector) {
        const zone = document.querySelector(selector);
        return zone ? Array.from(zone.children).map(card => card.title) : [];
    }

    function loadData() {
        const savedData = localStorage.getItem('movieTierData');
        const data = savedData ? JSON.parse(savedData) : { unclassified: initialMovies, S:[], A:[], B:[], C:[] };
        
        const zones = [
            document.querySelector('.tier-row:nth-child(1) .drop-zone'),
            document.querySelector('.tier-row:nth-child(2) .drop-zone'),
            document.querySelector('.tier-row:nth-child(3) .drop-zone'),
            document.querySelector('.tier-row:nth-child(4) .drop-zone')
        ];
        const keys = ['S', 'A', 'B', 'C'];

        keys.forEach((key, idx) => {
            if(data[key]) data[key].forEach(t => zones[idx].appendChild(createMovieCard(t)));
        });
        if(data.unclassified) data.unclassified.forEach(t => document.getElementById('unclassified').appendChild(createMovieCard(t)));
    }

        const savedData = localStorage.getItem('movieTierData');
        if (!savedData) return alert("저장할 데이터가 없습니다.");
        const blob = new Blob([savedData], { type: "application/json" });
        const url = URL.createObjectURL(blob);
        const a = document.createElement('a');
        a.href = url;
        a.download = "my_movie_tier_list.json";
        a.click();
        URL.revokeObjectURL(url);
    }

### 💡 변경된 핵심 포인트

1. **선택 상태(State) 관리:** `selectedCard` 변수를 만들어 현재 어떤 카드가 선택되었는지 추적합니다.
2. **시각적 피드백:** 카드를 클릭하면 흰색 테두리와 그림자 효과(`selected` 클래스)가 나타나 선택되었음을 알려줍니다.
3. **이벤트 전파 방지(`stopPropagation`):** 카드를 클릭했을 때 부모 요소인 '등급 행'의 클릭 이벤트가 동시에 발생하는 것을 막아, 클릭하자마자 이동하는 버그를 해결했습니다.
4. **영역 클릭 이동:** 등급 행(`tier-row`)이나 미분류 영역을 클릭하면, 현재 선택된 카드가 있다면 그곳으로 이동시킵니다.
5. **선택 취소:** 카드를 다시 클릭하거나, 빈 바탕화면을 클릭하면 선택이 해제되도록 하여 편의성을 높였습니다.
